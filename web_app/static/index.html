TaxFlow Pro — Help Guide
Quick start: (1) Add or select a client in Client Management → (2) Upload Returns on that client's card with your GSTR-1 JSON/ZIP → (3) Go to TallyPrime XML Export, generate the XML, and import it into a running TallyPrime instance.

  • Click Add New Client and enter the taxpayer's GSTIN, name, and (optionally) their GST portal login. PAN and State are auto-derived from the GSTIN.
  • Click a client card's Select Taxpayer to make it the active client — every other tab (Monthly Breakdown, Counterparties, Transactions, XML Export) then works only on that client's data.
  • Use Upload Returns on a client card to ingest a GSTR-1 JSON or ZIP file straight from the GST portal. The filename should contain the return type and financial year so the app can sanity-check it against the selected period.
  • Only the extracted invoice data is stored — raw uploaded JSON/ZIP files are parsed once and discarded, never written to disk.

One row per uploaded return period, with a document-type breakdown and tax totals:

  • B2B — standard registered-party sales invoices (incl. amendments)
  • B2C — unregistered-consumer sales, both small consolidated (B2CS) and single large interstate invoices >₹2.5L (B2CL)
  • CDNR — credit & debit notes, against registered or unregistered parties
  • EXP — export invoices (zero-rated, with or without IGST payment)
  • ADV — GST paid on advances received, and its later adjustment against a raised invoice

Use on a row to delete just that period, or Clear Returns to wipe every period for the client.

  • Lists every distinct GSTIN found across the client's uploaded invoices, with the Trade/Legal name that will be used for its Tally ledger.
  • Verify via GST Portal launches an automated, headless lookup against the official GST portal to fetch the real registered Trade Name, Legal Name, and status for each GSTIN. You'll be asked to solve one CAPTCHA per login attempt on-screen; verified names are then saved permanently and reused on every future export.
  • You can also manually edit a party's Trade/Legal name at any time — manual edits are saved permanently and take priority.
  • The Trade Name / Legal Name toggle (in the top toolbar) switches which name is used to build every ledger across the whole app.

Every normalized document behind the summary numbers — searchable by invoice number, GSTIN, or party name, and filterable by type (B2B, B2C Large, B2C Retail, Exports, Advances, Credit/Debit Notes). This is the place to spot-check a number before it goes into Tally.

  1. Generate XML builds two files from the currently loaded data: Consolidated_Masters.xml (ledgers to create) and Consolidated_Entries.xml (vouchers to post).
  2. Download them for manual import via Tally's Import Data menu, or click Import to Tally to POST them directly over HTTP.
  3. Direct import requires TallyPrime to be running locally with its HTTP server enabled on port 9000 (Gateway of Tally → F1 Help → Settings → Connectivity). The status pill in the top-right shows whether it's currently reachable.
  4. Always import Masters before Entries — vouchers reference ledgers that must already exist in the company.

  • "Cannot connect to TallyPrime" — Tally isn't running, the company isn't open, or the HTTP server / port 9000 isn't enabled. Click the status pill to re-check.
  • Upload rejected for filename/FY mismatch — the uploaded file's name must contain the GSTR return type and financial year so it isn't accidentally filed under the wrong period.
  • Batch capped at 10,000 invoices — split very large returns month-on-month (MOM) before uploading.
  • Zero-value invoices are intentionally excluded from the XML — they carry no accounting entry.
  • GST portal verification stuck on a CAPTCHA — you have 5 minutes to type the answer shown; it retries automatically up to 3 times on a wrong answer before failing that GSTIN.
  • GSTR-2B (purchase-side ITC) ingestion is not yet supported — this release covers GSTR-1 (sales) only.
All processing is local — no invoice data ever leaves this machine except to your own Tally instance.
